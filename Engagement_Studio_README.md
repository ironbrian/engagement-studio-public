# Engagement Studio

**A full-stack Azure engineering project exploring secure cloud applications, data services and AI integration.**

Engagement Studio is an independent software engineering project used to develop and demonstrate modern application delivery skills: web development, Azure infrastructure, identity, persistence, deployment automation and operational testing.

Its commercial purpose, business workflows and detailed solution design are intentionally omitted from this public overview.

## Technology stack

| Area | Technologies and approaches |
| --- | --- |
| Web application | Next.js, modern web application architecture |
| Cloud hosting | Azure Container Apps, containerised application deployment |
| Database | Azure SQL, relational data and application persistence |
| Storage | Azure Blob Storage |
| Security and identity | Microsoft Entra ID, managed identities, role-based access control (RBAC) |
| AI integration work | Azure AI Foundry, Azure OpenAI and related service integration patterns |
| Infrastructure as code | Bicep, Azure CLI |
| Automation | PowerShell, repeatable installation and deployment scripts |
| Software delivery | VS Code, Git, GitHub, versioned releases and automated tests |

## Engineering highlights

- Built and deployed a web application to Azure Container Apps, integrating Azure SQL and supporting Azure services.
- Worked through application authentication, managed identity, cloud permissions and database access.
- Used Bicep and PowerShell to automate Azure infrastructure and application deployment activities.
- Built repeatable operational tooling for environment setup, updates, verification and controlled teardown.
- Developed automated and regression tests across application and deployment components.
- Explored integration of Azure-hosted AI capabilities into a conventional web application stack.

## Key technical themes

### Cloud-native application delivery

Container-based hosting, application configuration, Azure-managed services, infrastructure deployment and operational troubleshooting.

### Security by design

Practical implementation of Entra authentication, managed identity, Azure role assignments and database permissions, including diagnosing real deployment issues.

### Infrastructure automation

Using Bicep, Azure CLI and PowerShell to make deployments more repeatable and reduce manual configuration.

### Software engineering quality

Version control, automated tests, regression checks, structured troubleshooting and an incremental development workflow.

### Applied AI integration

Working with the Azure AI ecosystem as part of a broader application architecture. AI integration is an area of development and is not presented here as a verified production capability.

## Project status

**Working Azure-hosted engineering prototype, under active development.** Core web hosting, Azure SQL connectivity, identity configuration and deployment tooling have been exercised. Some integration and application acceptance work has required further iteration; this is not represented as a completed enterprise production rollout.
